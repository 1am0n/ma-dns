# ma-dns
How does DNS resolution work? Magic? Yeah, of course it's magic! But even magic can be explained and understood.

Dig deeper into the world of DNS. It's strange, mysterious, and confusing, but I can simplify it enough to make sense of it. Can I? Let's try and find out.

### What this is?
DNS resolution in PHP, with a few of the most important server types implemented, root servers, TLD servers, an ISP's recursive resolver, and authoritative nameservers. Includes basic browser and device simulation too (very, very basic, haha).

### For what? AI knows everything already
Yeah. But I don't. To understand things better, I like to write them myself and see how they work.

### Haha, it's wrong
Of course it's wrong. Did you really think it would work properly? My English is broken, so my DNS is definitely even more broken.

### What's missing?
Oh... so so much. Better UDP queries, TCP fallback, caching, compression, nicer and better code, better server types implementation and God knows what else.

### How to run it?!?
Quite simple. You can use Docker with a PHP service. Don't forget to install Composer too.
